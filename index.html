大阪市住吉区のくらしの手続きを、
すみとよしがやさしく解説します

「すみとよしの住吉区てつづき帳」は、大阪市住吉区にお住まいの方に向けて、相続・各種許認可・引っ越しなどの行政手続きをわかりやすく解説する YouTube チャンネルです。

YouTube チャンネルを見る（@sumiyoshi_tetsuzuki）

すみ
解説役。正確さを大事にする落ち着いた猫。
よし
質問役。みんなと同じ目線で疑問をぶつける元気な犬。

このチャンネルの方針

  • 期限・手数料・窓口などの情報は、法令や官公庁の公式ページなどの一次情報で確認し、出典を概要欄に載せます。
  • 動画は一般的な解説です。個別の手続きは、窓口や専門家にご確認ください。
  • 当チャンネルは大阪市・住吉区役所の公式チャンネルではありません。

動画アップロードツールについて

当チャンネルでは、自作の動画を当チャンネルへアップロードするために、YouTube Data API を利用した運営者専用のツール「すみとよし アップロードツール」を使用しています。このツールは運営者のみが使用し、一般の方に提供するものではありません。取り扱う情報についてはプライバシーポリシーをご覧ください。

About the upload tool (English): This channel uses "Sumi and Yoshi Upload Tool", an operator-only tool built on YouTube API Services (the YouTube Data API), to upload its own videos to its own YouTube channel. The tool is not provided to the public. See the Privacy Policy and Terms of Service.
