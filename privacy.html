プライバシーポリシー

制定日：2026年10月9日 ／ 改定日：2026年10月18日 ／ English version

すみとよしの住吉区てつづき帳（以下「当チャンネル」）は、運営者専用の動画アップロードツール「すみとよし アップロードツール」（以下「本ツール」）および当ウェブサイトにおける情報の取り扱いについて、以下のとおり定めます。

1. 本ツールが利用するデータ

本ツールは YouTube API サービス（YouTube Data API）を利用し、Google の OAuth 2.0 による認可を受けて、当チャンネルの運営者自身の YouTube アカウントに対してのみ次の操作を行います。

  • 運営者が制作した動画のアップロード
  • 動画のタイトル・説明文・サムネイル等の設定

本ツールが要求する権限は https://www.googleapis.com/auth/youtube.upload のみです。運営者以外のユーザーのアカウントやデータにはアクセスしません。

2. 認証情報の保管

認可によって発行される認証情報（トークン等）は、運営者が管理する環境にのみ保管し、第三者に提供・公開しません。本ツールの利用目的以外には使用しません。

3. データの保存期間と削除

本ツールは、YouTube API サービスから取得したデータ（アップロード結果の動画 ID など）を保存しません。保管しているのは、上記 2 の認証情報（トークン等）だけです。

運営者が本ツールへのアクセス権を取り消した場合、または本ツールの利用をやめた場合は、保管している認証情報を 7 日以内に削除します。データの削除に関するご依頼は、下記のお問い合わせ先で受け付け、7 日以内に対応します。

4. 第三者への提供

本ツールを通じて取得したデータを、第三者に販売・提供・共有することはありません。

5. Google API サービスの利用について

本ツールによる Google API から受け取った情報の利用および他のアプリへの転送は、限定的使用の要件を含む Google API サービスのユーザーデータに関するポリシーに準拠します。

本ツールは YouTube API サービスを利用しています。本ツールの利用には YouTube 利用規約が適用され、データの取り扱いについては Google プライバシーポリシーもあわせてご確認ください。

6. アクセス権の取り消し

本ツールに付与したアクセス権は、Google アカウントのセキュリティ設定（サードパーティ製のアプリとサービス）からいつでも取り消すことができます。

7. 当ウェブサイトの閲覧について

当ウェブサイトは静的なページのみで構成されており、閲覧者の個人情報を収集するフォームや、当チャンネル独自のアクセス解析・Cookie は使用していません。なお、当ウェブサイトの配信基盤（GitHub Pages）を提供する GitHub, Inc. が、サービス運営のためにアクセスログ等を取得する場合があります。

8. お問い合わせ

本ポリシーに関するお問い合わせは、sumitoyoshi@gmail.com までご連絡ください。

9. 改定

本ポリシーは必要に応じて改定することがあります。改定した場合は、このページに掲載した時点から効力を生じます。

Privacy Policy (English)

Effective: October 9, 2026 / Last updated: October 18, 2026. The Japanese version above is the original; this English version has the same content.

This policy describes how "Sumi and Yoshi's Sumiyoshi-ku Procedures Notebook" (the "Channel") handles information in its operator-only video upload tool, "Sumi and Yoshi Upload Tool" (the "Tool"), and on this website.

1. Data used by the Tool

The Tool uses YouTube API Services (the YouTube Data API). With authorization through Google OAuth 2.0, it performs the following operations only on the Channel operator's own YouTube account:

  • Uploading videos produced by the operator
  • Setting the title, description, thumbnail and similar details of those videos

The only permission the Tool requests is https://www.googleapis.com/auth/youtube.upload. It does not access any other user's account or data.

2. Storage of credentials

Credentials issued by the authorization (such as tokens) are stored only in an environment managed by the operator. They are never provided or disclosed to third parties and are used only for the Tool.

3. Data retention and deletion

The Tool does not store any data obtained from YouTube API Services (such as the ID of an uploaded video). The only stored data are the credentials described in section 2.

If the operator revokes the Tool's access or stops using the Tool, the stored credentials are deleted within 7 days. Requests to delete data can be sent to the contact address below and will be handled within 7 days.

4. Sharing with third parties

Data obtained through the Tool is never sold, provided or shared with third parties.

5. Use of Google API Services

The Tool's use and transfer of information received from Google APIs to any other app adheres to the Google API Services User Data Policy, including the Limited Use requirements.

The Tool uses YouTube API Services. By using the Tool, you agree to be bound by the YouTube Terms of Service. See also the Google Privacy Policy.

6. Revoking access

Access granted to the Tool can be revoked at any time from the Google Account security settings (third-party apps and services).

7. This website

This website consists only of static pages. It has no forms that collect personal information and uses no analytics or cookies of its own. GitHub, Inc., which provides the hosting service (GitHub Pages), may collect access logs to operate its service.

8. Contact

For questions about this policy, contact sumitoyoshi@gmail.com.

9. Changes

This policy may be updated as needed. Changes take effect when posted on this page.
